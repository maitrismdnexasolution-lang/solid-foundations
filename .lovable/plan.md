# Restore the Uploaded Website Exactly

## Goal
Use the uploaded website package as the live project without redesigning or rewriting it.

## Implementation
- Copy the uploaded source code, pages, components, styling, fonts, images, metadata, and public files into this project.
- Preserve the uploaded website’s existing layout, colors, typography, text, animations, navigation, and mobile behavior exactly.
- Keep the existing TanStack setup and install only the dependencies already declared by the uploaded package.
- Do not add new sections, redesign elements, or alter any visible content.

## Verification
- Confirm the main page and included service pages load successfully.
- Compare desktop and mobile screenshots against the imported website itself to ensure the copy introduces no visual changes.
- Check navigation and key interactive controls for runtime errors.
